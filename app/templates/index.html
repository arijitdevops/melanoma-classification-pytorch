Classify a dermoscopic image

Upload a single lesion photograph. The model returns a benign/malignant probability and a Grad-CAM heatmap showing which image regions drove the prediction.

JPG, PNG, BMP or WebP, up to 8 MB.

How to read the output

  • The probability is the model's confidence, not a measure of risk.
  • The Grad-CAM overlay highlights pixels that most increased the malignant logit. It explains the model, not the biology.
  • The decision threshold defaults to 0.50. Tune it with python -m src.evaluate, which reports a high-sensitivity operating point as well.
